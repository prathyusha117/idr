# Institute of Digital Risk (IDR) – Brand and Homepage Design

## Project Overview

This project presents a **brand concept and responsive homepage** for the **Institute of Digital Risk (IDR)**. The goal of the assignment is to design a clean brand identity and develop a single-page responsive website that clearly explains the institute’s mission, services, and community.

The website is built using **semantic HTML5, CSS3, and vanilla JavaScript**, following modern frontend development practices while avoiding the use of CSS frameworks.

---

## Features

* Responsive layout for **desktop and mobile devices**
* **Sticky navigation bar** with smooth scrolling
* **Hero section** highlighting IDR’s mission
* **About section** explaining the institute’s role
* **Service pillars** displayed using responsive cards
* **Community section** describing target users
* **Contact / Register Interest form**
* Hover effects for navigation links, buttons, and cards
* Minimalist UI using the **orange, black, and white** color palette

---

## Logo Design

The logo uses a **cube-inspired geometric design** to represent structure, resilience, and layered digital risk frameworks.

### Logo Variants

1. **Icon-only version** – suitable for favicon and mobile header
2. **Icon + text version** – displaying “Institute of Digital Risk”

### Design Concept

* **Orange** represents innovation and digital technology.
* **Black** represents security, authority, and trust.
* **White** provides clarity and readability.

The cube form visually symbolizes structured frameworks used in digital, cyber, and AI risk management.

---

## Technology Stack

The project uses the following technologies:

* **HTML5** – Semantic structure
* **CSS3** – Styling and responsive layout using Flexbox
* **JavaScript** – Smooth scrolling interaction
* **Google Fonts** – Inter font family

No external frameworks such as Bootstrap were used.

## How to Run the Project

Follow these steps to run the website locally:

1. **Download or clone the project folder** to your computer.

2. Open the folder in a code editor such as **VS Code** or any text editor.

3. Locate the file:

index.html

4. Double-click the file or open it using any modern web browser such as **Chrome, Edge, or Firefox**.

5. The website will load and you can navigate through the sections using the navigation menu.

No additional setup or installation is required because the project uses only **HTML, CSS, and JavaScript**.
